## Подготовка к бете (Спринты 1–3, реализовано)

После вертикального среза доделана инфраструктура для закрытой беты на
10 человек. См. `git log --oneline` для деталей. Кратко:

| Шаг | Коммит | Что закрывает |
|---|---|---|
| A | `1adafef` | Baseline-коммит, проверка `.gitignore` / secrets validation |
| B | `504389e` | Роль `admin`, `INITIAL_ADMIN_EMAIL`, `get_admin_user` dependency |
| C | `9aff752` | SMTP Yandex + ARQ-очередь + 24ч TTL email-верификации |
| D | `7bbe945` | Инвайт-коды (BIP32, 7 дней) + 3 режима регистрации |
| E | `fd19de5` | AES-256-GCM + двухслойная DEK/KEK + Argon2id + Redis_keys без persistence |
| F | `a8a0222` | BIP39 мнемоника + reset-password + wipe-account |
| G | `8950ee6` | Система support-тикетов с плавающей кнопкой и админ-API |
| H | `146f001` | Полная админ-панель UI (дашборд, юзеры, инвайты, тикеты, настройки) |
| I | `0c17fe9` | Отдельный admin-Telegram-бот + push-уведомления |
| J | `5f0cc5f` | GlitchTip/Sentry SDK с PII-фильтром + настраиваемые квоты |
| K | `6048724` | Экспорт данных + удаление аккаунта (ФЗ-152) |
